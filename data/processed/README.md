# Processed Data

These files are generated by `src/preprocessing.py`.

## Expected outputs

- `train_clean.csv` — cleaned training reviews and labels.
- `test_clean.csv` — cleaned test reviews and labels after train/test overlap removal.
- `train_tfidf.npz` — sparse TF-IDF training feature matrix.
- `test_tfidf.npz` — sparse TF-IDF test feature matrix.
- `train_labels.csv` — training labels.
- `test_labels.csv` — test labels.
- `tfidf_vectorizer.joblib` — training-fitted TF-IDF vectorizer.
- `tfidf_features.csv` — TF-IDF feature names.
- `data_quality_audit.csv` — data-quality and leakage audit.

## Important

The raw IMDb archive and raw CSV copies are intentionally excluded from Git.

The TF-IDF matrices are stored as sparse CSR/NPZ rather than dense CSV because the final feature space contains 433,653 columns. A dense CSV representation would be unnecessarily large and inefficient. The audit records the exact matrix dimensions and non-zero counts.

The vectorizer is fitted on training data only; the test set is transformed using that same training-fitted vectorizer to prevent feature leakage.
