# EchoMedia Analytics

## IMDb Movie Review Sentiment Analysis

### Project Overview

EchoMedia Analytics is an NLP-based machine learning project
that classifies movie reviews as positive or negative.

## Objective

- Perform sentiment classification
- Apply TF-IDF text vectorization
- Handle out-of-vocabulary words
- Compare machine learning models
- Evaluate using Accuracy, Balanced Accuracy and Macro F1
- Deploy the model through a user interface
- Build a Power BI analytics dashboard

## Dataset

Stanford IMDb Large Movie Review Dataset
